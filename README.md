# AHDF Frontend Website

Responsive static frontend built with HTML5, custom CSS, JavaScript and Bootstrap 5.3.

## Run
Open `index.html` directly, or serve the folder with any local web server.

Example:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Navigation/pages
- Home
- Who We Are: About Foundation, Mission & Vision, Founder & Directors, International Directors, President Message
- What We Do: Our Programmes, Our Activities, Our Projects
- Where We Work: International Cooperation, Our Partners
- Memberships: Membership List, Code of Conduct, Membership Process, Member Services
- News & Events: Gallery, Videos, Latest News, Blogs, Activity Reports
- Contact Us

## Content integrity
Website content is drafted from the supplied AHDF Memorandum / Rules and Board assignment documents. Where the source documents do not provide verified current partners, active projects, news, photos or videos, the website clearly labels proposed/placeholder content rather than inventing facts.

## Before publishing
1. Replace placeholder contact details with official AHDF email/phone.
2. Approve the drafted Mission/Vision, President Message and Code of Conduct.
3. Add verified partner logos, project records, news, event photos and videos.
4. Connect the contact form to a backend/API.
5. If needed, convert the static pages to your CMS/backend templates.

- `membership-application.html` — responsive AHDF membership application form based on the supplied official PDF.
